# Extension contract examples

These fictional examples exercise the incubating contracts in `../extensions/`.

- `media-real-capture.request.example.json` requires camera-captured media and forbids synthesized pixels, video, voice, and identity media.
- `media-real-capture.asset-record.example.json` demonstrates file hashes, non-generative edits, release references, rights review, accessibility, QA, and an internal approval that still does not authorize publishing.
- `supervisor-preference-intake.example.json` stores structured owner choices and labeled scenarios without a raw interview transcript.
- `supervisor-policy-profile.example.json` is approved only for shadow evaluation.
- `supervisor-shadow-decision.example.json` shows the Supervisor decision beside the later human decision; it does not apply the decision or perform an external action.

All tenant, campaign, file, release, and evidence references are synthetic.
