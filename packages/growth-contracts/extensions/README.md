# Incubating media and Supervisor contracts

These contracts define the proposed data boundary for two capabilities that are not activated in the local alpha:

- evidence-bound production of real, owned, licensed, generated, and hybrid media;
- a Pro Supervisor that can make bounded decisions after owner calibration.

They live outside `contract-index.json` on purpose. Adding a schema here does not add a workflow, grant approval authority, connect a media store, call a model, publish content, or enable unattended execution. Promotion into the active contract index requires implementation, threat review, migration/versioning work, and an explicit release decision.

The examples in `../examples/` are fictional and contain references rather than binary media, releases, identities, credentials, or raw interview transcripts.
