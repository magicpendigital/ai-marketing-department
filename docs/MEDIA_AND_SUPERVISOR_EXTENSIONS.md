# Media and Pro Supervisor extensions

These two designs extend the local Canvas concept without changing its current draft-only authority:

1. [Media provenance and production workflow](MEDIA_PROVENANCE_WORKFLOW.md) defines real capture, owned/licensed assets, generation policy, capture briefs, rights/releases, private ingest, edit provenance, QA, internal approval, and a separate publishing gate.
2. [Pro Supervisor operating model](PRO_SUPERVISOR_OPERATING_MODEL.md) defines structured owner calibration, decision history, shadow evaluation, bounded autonomy, confidence/novelty/risk gates, audit, escalation, and a kill switch.

The matching schemas and fictional examples live under [`packages/growth-contracts/extensions`](../packages/growth-contracts/extensions/README.md) and [`packages/growth-contracts/examples`](../packages/growth-contracts/examples/README.md). They are intentionally outside the active contract index until implementation and release review are complete.
