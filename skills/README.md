# Marketing AI skill pack

This pack gives a new tenant the same draft-only operating capability for readiness, research, positioning, content, quality review, measurement, execution preflight, and learning.

## Install

Keep each skill folder intact and place the whole \`skills\` directory where the project’s agent runtime discovers repository-scoped skills. Preserve the folder names because the workflow catalog refers to them. Read the selected skill before starting its workflow; it supplements the repository contracts and governance documents.

Do not copy a completed tenant’s BrandPack, ProductTruth, sources, drafts, approvals, customer records, or operating history into another tenant. Complete the new tenant onboarding pack first.

## Operating boundary

All eight skills create or review internal artifacts only. They do not authorize or perform outreach, publishing, scheduling, paid-media activity, channel connection, account access, product changes, or automated optimization. A named human must make every gate decision.

| Skill | Use it for | Primary handoff |
| --- | --- | --- |
| growth-readiness | Establish a trustworthy tenant starting point | Readiness record |
| growth-research | Convert approved material into bounded hypotheses | Research plan and JTBD hypotheses |
| growth-positioning | Form a testable value hypothesis | Experiment brief |
| growth-content-factory | Produce a traceable internal content package | Concept and copy package |
| growth-quality-gate | Independently evaluate a package | QA verdict and repair request |
| growth-journey-measurement | Define aggregate measurement | Journey measurement plan |
| growth-execution-preflight | Prepare a future-gate evidence package | Preflight checklist |
| growth-learning-synthesis | Turn approved aggregate results into learning | Learning note and product-ticket draft |

Use the skills in workflow order: readiness, research and positioning, content and quality, then measurement and learning. Execution preflight records requirements for deferred workflows; it does not enable execution.
